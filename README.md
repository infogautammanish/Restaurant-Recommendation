# Cognifyz Machine Learning Internship - Restaurant Data Analysis

## 📌 Overview
This project contains the solution for the Cognifyz Technologies Machine Learning Internship program. The analysis is performed on a restaurant dataset to predict ratings, recommend restaurants, classify cuisines, and analyze geographical patterns.

## 🎯 Tasks Completed

### Task 1: Predict Restaurant Ratings
- Built a **Random Forest Regressor** to predict aggregate restaurant ratings
- Achieved **R² Score** and **MSE** evaluation
- Identified top features influencing ratings

### Task 2: Restaurant Recommendation System
- Created a **Content-Based Filtering** system
- Used **TF-IDF Vectorization** and **Cosine Similarity**
- Recommends similar restaurants based on cuisine and location

### Task 3: Cuisine Classification
- Developed a **Random Forest Classifier** to classify restaurant cuisines
- Evaluated using **Accuracy** and **Per-Cuisine Performance**
- Handled multi-class classification with class imbalance

### Task 4: Location-based Analysis
- Performed geographical analysis of restaurant distribution
- Visualized restaurant locations on a map
- Analyzed city-wise and locality-wise statistics
